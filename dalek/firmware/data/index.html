Connect to your robot

The same key joins the DALEK Wi-Fi access point. Your robot can also join a 2.4 GHz WPA2 network.

Reading robot status…

Arm, then hold a movement button. Release to stop and disarm. A lost connection stops motion. A screen lock or another tab also disarms.

Turns use forward arcs to reduce tire drag. Start with the wheels lifted. Speed is limited for commissioning.

Arms and head

Head speed and arm circles apply only while a movement or animation button is held. Keep fingers away from arm joints and the neck.

Voice

Original synthesized robot phrases. Sound works while motion is disarmed.

Wi-Fi network settings

This disarms motion. The setup access point stays available. Read the network IP on the rear display. Use only a private network you trust.
